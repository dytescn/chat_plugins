# 构建与测试

## 构建

```bash
cd deepseek
cargo build --release

cd ../siliconflow_t2t
cargo build --release
```

产物：

- `deepseek/target/release/libdeepseek.dll`
- `siliconflow_t2t/target/release/siliconflow_t2t.dll`

具体导出文件名以各自 `dytes.json` 为准。

## 单元测试

```bash
cargo test
```

测试应覆盖：

- `setting.rs` 的配置解析与默认值；
- 请求 JSON 的字段解析；
- 错误码与统一响应包络；
- 不依赖外部 API 的纯函数。

真实 API 测试必须显式使用本地配置，不能把 Key 写进测试代码。

## 插件测试

插件测试使用 `plugintest/`，启动 cyctron 后通过 HTTP 调用 `post_chat`。
详细步骤见 [3.plugintest.md](3.plugintest.md)。

## 编译环境

- Rust stable；
- Windows 下需要 MSVC 工具链；
- `Cargo.lock` 必须提交，构建时使用 `--locked` 或避免无意 `cargo update`；
- 修改依赖后同时检查两个插件的 `Cargo.lock`。

## 提交前检查

```bash
cargo fmt --all -- --check
cargo test
cargo build --release
git diff --check
```
