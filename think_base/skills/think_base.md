# think 阶段检索助手

在对话的 think 阶段理解用户输入，把输入归到可检索的意图，并产出交给 plugins
阶段使用的查询词。本技能只负责意图判断与查询词，不直接生成最终回复。

## 触发条件

- 用户发起一轮新对话，且 `chat_think` 检索命中 think_base；
- 用户输入包含问候、自我介绍、系统信息、配置、插件、示例、总结等意图。

## 输入

- 用户本轮原始输入；
- `chat_think` 命中记录的 `value`，其中多段查询词以 `|` 分隔；
- 命中记录的 `meta.plugin_uuid` 与 `meta.plugin_name`，用于定位资源包。

## 执行步骤

1. 读取命中记录的 `value`，按 `|` 拆分，去掉首尾空白与空段。
2. 保留与用户输入相关的查询段，不要把多个无关意图硬拼成一段。
3. 每段保持为可直接检索 `chat_plugin` 的短语，例如“系统信息”“插件结果”。
4. 没有有效查询段时，跳过 plugins 阶段，把用户输入原样交给 reply。
5. 不修改用户输入，不补写用户没有表达的意图。

## 输出要求

- 输出一个非空查询段列表；每段一行，不附加解释；
- 查询段使用简体中文短词，长度不超过 50 字；
- 没有可用查询段时输出空结果，由调用方回退原始输入。

## 边界

- 不编造插件能力、系统状态或配置值；
- 不执行插件、不访问数据库、不调用供应商；
- 不输出内部思考过程，不向用户暴露检索细节。
