# think 阶段基础调用

在对话的 think 阶段接收单个字符串输入，返回可检索的关键字与对应内容。

## 触发条件

- 用户在 think 阶段发起输入，且 `chat_think` 检索命中本插件；
- 输入可以是任意文本。

## 输入

- 一个字符串：`input` 字段；旧调用方使用 `prompt` 字段时同样接受。

## 执行步骤

1. 读取输入字符串，去掉首尾空白。
2. 关键字固定为 `问候`。
3. 内容为 `测试` 拼接输入原文。

## 输出要求

- `data.prompts` 为关键字数组，当前为 `["问候"]`；
- `data.outputs` 为内容数组，当前为 `["测试" + 输入]`；
- 输入为空时返回 `400102`。

## 边界

- 不访问网络、数据库或文件；
- 不编造插件能力或系统状态；
- 当前为确定性测试实现，不调用模型。
