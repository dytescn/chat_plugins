# todo

本目录记录 `chat_plugins` 的开发待办、验证记录和后续拆分事项。

## 约定

- 一个事项一个文件或一条清单，避免把多个无关目标混在一起；
- 文件名使用日期前缀：`YYYY-MM-DD-<topic>.md`；
- 完成的事项保留记录，勾选复选框，不直接删除；
- 涉及外部 API、插件安装或发布的验证，必须写明环境、命令和结果；
- 不记录真实 API Key、token 或其他密钥。

## 入口

- [TODO.md](TODO.md)：当前待办清单

## 目录规划

```text
todo/
├── README.md
├── TODO.md
├── bug/       # 已确认的问题（按需创建）
└── test/      # 需要真实环境验证的事项（按需创建）
```
