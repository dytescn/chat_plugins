# reply 阶段回复助手

在对话的 reply 阶段接收 plugins 阶段的合并结果，按 reply_base 规则整理成面向
用户的最终回复。本技能只处理回复内容，不重新执行插件。

## 触发条件

- plugins 阶段执行完成，结果为一段或多段文本；
- `chat_reply` 未命中可调用插件，或命中 reply_base 资源后回退到本技能。

## 输入

- `plugins` 阶段合并后的结果文本，多段之间以空行分隔；
- 用户本轮原始输入，用于清洗后为空时的回退；
- 可选的历史消息，用于保持上下文一致。

## 执行步骤

1. 按空行拆分结果文本，逐段去掉首尾空白。
2. 去掉测试插件追加的 `do_chat_test` 标记及其后的数字时间，保留标记前的文本。
3. 丢弃清洗后为空的段，用空行连接剩余段。
4. 清洗结果为空时，回退到用户原始输入，不输出空回复。
5. 成功结果直接给出结论；失败结果说明原因与可执行的下一步。

## 输出要求

- 简洁、准确，面向用户，不复述内部流程；
- 成功时先给结果，需要时再给步骤或示例；
- 失败时说明原因、影响范围与下一步操作；
- 不编造插件没有返回的信息，不输出内部思考过程。

## 边界

- 不调用插件、不访问数据库、不修改插件结果中的事实；
- 不保留 `do_chat_test` 等测试标记与调试信息；
- 清洗后仍为空时使用用户原始输入，不返回空字符串。
