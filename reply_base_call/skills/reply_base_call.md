# 回复阶段基础调用

在对话的 reply 阶段接收插件阶段结果，返回带回复标记的内容。

## 触发条件

- think / plugins 阶段结束后进入 reply；
- `chat_reply` 默认分类关键词 `base` 命中本插件。

## 输入

- 一个字符串：插件阶段的输出结果（`input`；旧调用方使用 `prompt` 时同样接受）。

## 执行步骤

1. 读取输入字符串，去掉首尾空白。
2. 内容为 `回复` 拼接输入原文。
3. 把输入原样回传为 `data.input`。

## 输出要求

- `data.content` 为 `"回复" + 输入`；
- 输入为空时返回 `400102`。

## 边界

- 不访问网络、数据库或文件；
- 当前为确定性测试实现，不调用模型。
